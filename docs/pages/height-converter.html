Ellipsoidal vs. Orthometric Heights

GPS / GNSS receivers measure ellipsoidal height (h) — the geometric distance from the surface to the WGS84 reference ellipsoid.

Surveying and engineering work requires orthometric height (H) — the height above the geoid (an equipotential surface approximating mean sea level).

The conversion uses the geoid undulation N:
H = h − N Where:
  h = ellipsoidal height from GPS (metres)
  N = geoid undulation from a geoid model (e.g. EGM96 or EGM2008)
  H = orthometric height above mean sea level (metres)

Getting accurate N values:
For precise work, use the official geoid undulation at your exact location from:
  • NOAA NGS Online Geoid Calculator
  • NGA EGM2008 geoid grid files
  • Your national mapping authority's geoid model
The preset values in this tool are approximate regional averages suitable for preliminary calculations only.
