Concepts
h — Ellipsoidal height: height above the WGS84 reference ellipsoid, as measured by GPS/GNSS.
N — Geoid undulation: vertical separation between the ellipsoid and the geoid (equipotential surface approximating mean sea level). Positive N means the geoid is above the ellipsoid.
H — Orthometric height: height above the geoid, used in everyday surveying and engineering.

How to use this tool

  1. Obtain the geoid undulation N for your area from a geoid model (EGM2008, national model, or the reference table above).
  2. Enter your GPS-derived ellipsoidal height h.
  3. The tool computes H = h − N.
  4. For batch processing, paste or import a CSV file and use the Batch tab.
